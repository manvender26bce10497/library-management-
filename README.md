# 📚 Library Management System

## 📌 Project Description

The **Library Management System** is a simple Python-based project designed to manage books in a library.

The program allows the user to search for a book and immediately view its **book number, location, and available stock**. It also allows new books to be added and displays all the books stored in the system.

This project is developed using basic Python concepts such as **dictionaries, loops, conditional statements, functions, and user input**.

## ✨ Features

* 🔍 Search for a book
* 📍 Display book location
* 🔢 Display book number
* 📚 Display available stock
* ➕ Add a new book
* 📋 Display all books
* 🚪 Exit the program

## 🛠️ Technologies Used

* **Programming Language:** Python
* **Concepts Used:** Dictionary, Loop, If-Else, Input/Output
